# JS Beauty Parlour & Academy Website

A full-stack responsive salon website developed for **JS Beauty Parlour & Academy** to showcase salon services, offers, gallery, customer reviews, appointment booking, and admin dashboard management.

## Features

### Frontend Features

* Responsive modern UI
* Mobile-friendly design
* Salon service pages
* Gallery section
* Customer reviews section
* Appointment booking interface
* Contact page with location
* WhatsApp integration
* Admin dashboard UI

### Backend Features

* FastAPI backend integration
* SQLite database support
* REST API endpoints
* Booking management system
* Admin booking access
* Swagger API documentation

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Python
* FastAPI
* Uvicorn

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/roopauma1109-maker/Salon_Website_Project.git
cd Salon_Website_Project
```

### Install Backend Dependencies

```bash
pip install fastapi uvicorn
```

### Run Backend Server

```bash
cd backend
uvicorn main:app --reload
```

Backend runs at:

```bash
http://127.0.0.1:8000
```

API Documentation:

```bash
http://127.0.0.1:8000/docs
```
