# JS Beauty Parlour & Academy Website

A responsive frontend website developed for **JS Beauty Parlour & Academy** to showcase salon services, offers, gallery, reviews, and appointment booking features.

## Features

* Responsive modern UI
* Mobile-friendly design
* Salon service pages
* Appointment booking interface
* Gallery section
* Customer reviews section
* Contact page with location
* Admin dashboard UI
* WhatsApp integration

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```bash
images/        → Website images
pages/         → Additional website pages
index.html     → Homepage
style.css      → Main styling
script.js      → Website functionality
```

## Pages Included

* Home
* Services
* Gallery
* Offers
* Reviews
* Booking
* Contact
* Admin Dashboard
